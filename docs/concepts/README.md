# 概念の文書案内

**Status: active** | **Last updated: 2026-10-20**

このディレクトリでは、Lingonberryが知識をどのように表し、識別し、運ぶかを説明します。初めて読む場合は、次の順に確認してください。

## おすすめの読む順序

1. [概念モデル](./CONCEPT_MODEL.md): データの流れと、内容・識別情報・来歴・履歴の役割を把握する
2. [用語集](./GLOSSARY.md): 各用語の定義を確認する
3. [carrierの説明](./CARRIER.md): HTTPやファイルでデータを運ぶ仕組みと、プロトコルの役割の違いを理解する
4. [Toitoiアプリケーションプロファイル](../profiles/TOITOI_APPLICATION_PROFILE.md): 分野固有の語彙や追加制約を定める例を読む

## サンプルで確かめる

- [スキーマ案内](../../schemas/README.md): JSONの必須フィールドと公開要求の構造
- [サンプルデータ案内](../../fixtures/README.md): 正常例・不正例の見方と、ローカルでの動作確認
- [開発者向け文書](../developers/README.md): アプリケーションから公開・連携するための入口
